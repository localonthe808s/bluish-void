## 7. Fix on this branch

`index.html` (cwkYesterday, the "where yesterday stood" view) fetched
`cdn.bluishvoid.com/kalshi/trail/<key>_<yesterday>.jsonl` with no query string. It got whatever partial copy the edge
had pinned during that day. The view then takes the last row at or before each moment, so every moment showed the
last cached row.

The change is one line: `+ '?d=' + T.date`. The cache key becomes today's date, so the first fetch of that key happens
after yesterday's file is complete. A day's key is shared by every viewer, so the CDN still caches it.
